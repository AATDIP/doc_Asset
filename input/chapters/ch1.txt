บทนำ

1.1 ความเป็นมาและความสำคัญของปัญหา
คณะแพทยศาสตร์ โรงพยาบาลศรีนครินทร์ มหาวิทยาลัยขอนแก่น เป็นศูนย์กลางการให้บริการทางการแพทย์ การวิจัย และการจัดการเรียนการสอนทางการแพทย์ขนาดใหญ่ในภาคตะวันออกเฉียงเหนือ ประกอบด้วยภาควิชา ศูนย์ความเป็นเลิศทางการแพทย์ และหน่วยงานสนับสนุนการปฏิบัติงานจำนวนมาก ซึ่งแต่ละหน่วยงานมีพัสดุและครุภัณฑ์ทางการแพทย์ อุปกรณ์คอมพิวเตอร์และระบบอิเล็กทรอนิกส์ ตลอดจนเครื่องใช้สำนักงานที่ต้องใช้งานและอยู่ในความดูแลเป็นจำนวนมหาศาล การบริหารจัดการสินทรัพย์ (Asset Management) จึงเป็นกระบวนการที่มีความสำคัญอย่างยิ่ง เพื่อให้ทราบถึงสถานะความพร้อมใช้งาน ตำแหน่งที่ตั้ง ประวัติการซ่อมบำรุง และอายุการใช้งานของครุภัณฑ์แต่ละรายการได้อย่างถูกต้องและเป็นปัจจุบัน
อย่างไรก็ตาม ในปัจจุบันกระบวนการตรวจสอบและติดตามพัสดุและครุภัณฑ์ภายในคณะแพทยศาสตร์ยังประสบปัญหาในการเข้าถึงและการบริหารจัดการข้อมูล เนื่องจากระบบฐานข้อมูลและสิทธิ์ในการสืบค้นข้อมูลครุภัณฑ์ส่วนกลางถูกจำกัดไว้เฉพาะบุคลากรในแผนกพัสดุเท่านั้น ส่งผลให้เมื่อภาควิชาหรือหน่วยงานผู้ใช้งานต้องการตรวจสอบสถานะครุภัณฑ์ในความดูแลของตนเอง ค้นหาประวัติการโอนย้าย หรือตรวจสอบวันหมดอายุของสัญญาประกัน จะไม่สามารถดำเนินการสืบค้นข้อมูลได้ด้วยตนเองในทันที จำเป็นต้องทำเรื่องประสานงานและร้องขอข้อมูลผ่านทางแผนกพัสดุทุกครั้ง ก่อให้เกิดปัญหาคอขวดและความล่าช้าในการปฏิบัติงานของทั้งสองฝ่าย โดยหน่วยงานผู้ใช้งานต้องสูญเสียเวลารอคอยข้อมูล ในขณะที่แผนกพัสดุต้องแบกรับภาระงานในการตอบคำถามและค้นหาข้อมูลซ้ำซ้อนอย่างต่อเนื่อง
นอกจากปัญหาด้านการเข้าถึงข้อมูลแล้ว กระบวนการจัดการข้อมูลครุภัณฑ์ที่มีความซับซ้อนและมีปริมาณมากยังคงขาดเครื่องมืออำนวยความสะดวกที่มีประสิทธิภาพ โดยเฉพาะการนำเข้าและปรับปรุงข้อมูลสินทรัพย์ผ่านไฟล์ตารางทำการ ซึ่งขาดระบบตรวจสอบและเปรียบเทียบความแตกต่างของข้อมูลก่อนการบันทึกจริง รวมถึงเมื่อมีการโอนย้ายครุภัณฑ์ระหว่างแผนก การติดตามและบันทึกประวัติการเปลี่ยนแปลงยังทำได้ยาก ทำให้ข้อมูลคลาดเคลื่อนและตรวจสอบย้อนหลังได้ไม่ชัดเจน อีกทั้งยังขาดระบบสร้างรหัสคิวอาร์และระบบจัดพิมพ์ป้ายสติกเกอร์กำกับสินทรัพย์ที่เป็นมาตรฐานสำหรับติดบนอุปกรณ์เพื่อความสะดวกรวดเร็วในการตรวจนับหน้างาน
จากปัญหาและความต้องการดังกล่าว คณะแพทยศาสตร์ โรงพยาบาลศรีนครินทร์ มหาวิทยาลัยขอนแก่น จึงมีแนวคิดในการพัฒนาระบบบริหารจัดการสินทรัพย์ในรูปแบบเว็บแอปพลิเคชัน เพื่อเปิดโอกาสให้บุคลากรแต่ละหน่วยงานสามารถเข้าถึงและตรวจสอบข้อมูลครุภัณฑ์ในความรับผิดชอบของตนเองได้แบบเรียลไทม์ โดยผู้จัดทำได้รับมอบหมายให้รับผิดชอบการออกแบบและพัฒนาส่วนต่อประสานผู้ใช้และระบบการโต้ตอบฝั่งไคลเอนต์ทั้งหมด ซึ่งเป็นหัวใจสำคัญในการเชื่อมโยงระหว่างผู้ใช้งานกับระบบฐานข้อมูล ให้สามารถค้นหา กรองข้อมูล แสดงผลตารางสินทรัพย์ขนาดใหญ่ โอนย้ายสินทรัพย์ พิมพ์ป้ายรหัสคิวอาร์ และรองรับการใช้งานที่ยืดหยุ่นทั้งบนคอมพิวเตอร์และอุปกรณ์พกพา ซึ่งจะช่วยยกระดับประสิทธิภาพและความโปร่งใสในการบริหารจัดการสินทรัพย์ขององค์กรได้อย่างเป็นรูปธรรม

1.2 วัตถุประสงค์ของโครงงาน
1.2.1  เพื่อพัฒนาระบบบริหารจัดการสินทรัพย์ในรูปแบบเว็บแอปพลิเคชัน สำหรับคณะแพทยศาสตร์ โรงพยาบาลศรีนครินทร์ มหาวิทยาลัยขอนแก่น
1.2.2  เพื่อออกแบบและพัฒนาส่วนต่อประสานผู้ใช้ด้วยเทมเพลต EJS ร่วมกับ Bootstrap 5 ที่รองรับการสืบค้นและแสดงผลข้อมูลสินทรัพย์ขนาดใหญ่ พร้อมระบบตรึงหัวตาราง
1.2.3  เพื่อพัฒนาระบบส่วนติดต่อผู้ใช้สำหรับการโอนย้ายครุภัณฑ์ระหว่างแผนกแบบกลุ่มผ่านหน้าต่างโต้ตอบร่วมกับระบบค้นหาเลือกแผนกแบบพิมพ์แล้วค้นหา
1.2.4  เพื่อพัฒนาระบบสร้างรหัสคิวอาร์และระบบจัดพิมพ์ป้ายกำกับสินทรัพย์ขนาดมาตรฐานเจ็ดสิบคูณยี่สิบสี่มิลลิเมตรสำหรับติดบนอุปกรณ์
1.2.5  เพื่อพัฒนาระบบส่วนต่อประสานที่รองรับการใช้งานหลายขนาดหน้าจอ รองรับการสลับโหมดการแสดงผลโดยไม่มีการกระพริบของหน้าจอ และรองรับระบบสองภาษา

1.3 ขอบเขตของโครงงาน
1.3.1  ระบบพัฒนาบนสถาปัตยกรรมเว็บแอปพลิเคชันแบบจำลองมุมมองและตัวควบคุมร่วมกับการเรนเดอร์ส่วนติดต่อผู้ใช้ฝั่งเซิร์ฟเวอร์ด้วย EJS และควบคุมการทำงานด้วย Node.js ร่วมกับ Express
1.3.2  ส่วนต่อประสานผู้ใช้ได้รับการจัดโครงสร้างแบบคอมโพเนนต์ย่อยประกอบด้วยส่วนหัว แถบนำทาง แถบเมนูด้านข้าง และส่วนท้าย เพื่อความสม่ำเสมอในการแสดงผล
1.3.3  หน้าแดชบอร์ดรองรับการแสดงผลการ์ดสรุปยอดสินทรัพย์ แถบค้นหาและตัวกรองข้อมูลหลายมิติ และตารางแสดงข้อมูลสินทรัพย์ที่รองรับการเลื่อนทั้งแนวตั้งและแนวนอนพร้อมตรึงหัวตาราง
1.3.4  ระบบรองรับการนำเข้าข้อมูลสินทรัพย์ผ่านไฟล์ Excel พร้อมหน้าจอแสดงผลเปรียบเทียบข้อมูลก่อนการปรับปรุงโดยแยกการแสดงผลเป็นกลุ่มข้อมูลที่มีการเปลี่ยนแปลง ข้อมูลใหม่ และข้อมูลเดิม
1.3.5  ระบบรองรับการโอนย้ายสินทรัพย์ข้ามแผนกแบบกลุ่มผ่านหน้าต่างโต้ตอบโดยแสดงป้ายแผนกต้นทางอัตโนมัติและมีกล่องค้นหาแผนกปลายทางที่รองรับการนำทางด้วยแป้นพิมพ์
1.3.6  ระบบสามารถสร้างรหัสคิวอาร์ประจำสินทรัพย์และสร้างหน้าสำหรับพิมพ์ป้ายสติกเกอร์ขนาดเจ็ดสิบคูณยี่สิบสี่มิลลิเมตรพร้อมข้อมูลรหัสสินทรัพย์ คำอธิบาย สัญญา และวันหมดอายุ
1.3.7  ระบบจัดการเอกสารรองรับการสลับมุมมองระหว่างแบบตารางและแบบการ์ดพร้อมหน้าต่างแสดงตัวอย่างไฟล์ PDF ผ่านกรอบหน้าต่างที่สอดคล้องกับนโยบายความปลอดภัย
1.3.8  ส่วนต่อประสานผู้ใช้รองรับการแสดงผลแบบตอบสนองทั้งบนคอมพิวเตอร์และอุปกรณ์พกพาพร้อมระบบแถบเมนูข้างแบบลิ้นชักบนหน้าจอขนาดเล็ก
1.3.9  ส่วนต่อประสานผู้ใช้รองรับการสลับโหมดแสดงผลแบบสว่างและแบบมืดผ่านตัวแปรแบบเรียงซ้อนและมีกลไกป้องกันการกระพริบของหน้าจอ
1.3.10  ระบบรองรับการสลับภาษาในการแสดงผลระหว่างภาษาไทยและภาษาอังกฤษครอบคลุมป้ายกำกับ ข้อความแจ้งเตือน และกล่องข้อความยืนยันการทำงาน
1.3.11  ส่วนต่อประสานผู้ใช้แสดงผลเมนูและสิทธิ์การเข้าถึงข้อมูลตามบทบาทของผู้ใช้งานสามระดับ ได้แก่ ผู้ใช้งานทั่วไป ผู้ดูแลระบบ และผู้ดูแลระบบระดับสูง
1.3.12  ระบบจัดเก็บข้อมูลในระบบจัดการฐานข้อมูลเชิงสัมพันธ์ MySQL และมีการบันทึกประวัติการปฏิบัติงานของผู้ใช้แบบกลุ่มที่สามารถเรียกดูรายละเอียดรายการย่อยได้

1.4 ประโยชน์ที่คาดว่าจะได้รับ
1.4.1  บุคลากรและเจ้าหน้าที่แต่ละแผนกในคณะแพทยศาสตร์สามารถเข้าถึงและตรวจสอบข้อมูลสินทรัพย์ในความดูแลของตนเองได้อย่างสะดวกรวดเร็วและเป็นปัจจุบัน
1.4.2  ลดภาระงานและความซ้ำซ้อนของเจ้าหน้าที่แผนกพัสดุในการรับเรื่องและค้นหาข้อมูลสินทรัพย์ให้กับหน่วยงานต่างๆ
1.4.3  เพิ่มความถูกต้องและรวดเร็วในกระบวนการโอนย้ายครุภัณฑ์ระหว่างแผนก พร้อมทั้งสามารถตรวจสอบประวัติการทำรายการย้อนหลังได้อย่างโปร่งใส
1.4.4  อำนวยความสะดวกในการตรวจนับและสืบค้นข้อมูลครุภัณฑ์ภาคสนามด้วยระบบสแกนรหัสคิวอาร์และป้ายสติกเกอร์ที่ได้มาตรฐาน
1.4.5  ยกระดับประสบการณ์ของผู้ใช้งานด้วยส่วนต่อประสานที่มีความทันสมัย ใช้งานง่าย รองรับการแสดงผลทั้งภาษาไทย ภาษาอังกฤษ และโหมดการแสดงผลแบบถนอมสายตา

1.5 นิยามศัพท์เฉพาะ
1.5.1  ระบบบริหารจัดการสินทรัพย์ หมายถึง ระบบสารสนเทศในรูปแบบเว็บแอปพลิเคชันที่พัฒนาขึ้นเพื่อใช้ในการบันทึก ติดตาม ตรวจสอบสถานะ และโอนย้ายครุภัณฑ์ภายในคณะแพทยศาสตร์ โรงพยาบาลศรีนครินทร์ มหาวิทยาลัยขอนแก่น
1.5.2  ส่วนต่อประสานผู้ใช้ หมายถึง ส่วนของระบบที่แสดงผลบนหน้าจอเว็บเบราว์เซอร์เพื่อให้ผู้ใช้งานมีปฏิสัมพันธ์กับระบบ รวมถึงการออกแบบโครงสร้าง มุมมอง สไตล์ และสคริปต์การทำงานฝั่งไคลเอนต์
1.5.3  EJS หมายถึง ภาษาเทมเพลตสำหรับ Node.js ที่ช่วยให้สามารถสร้างโครงสร้างหน้าเอกสารเว็บด้วยการฝังรหัสโปรแกรม JavaScript ร่วมกับโครงสร้างภาษา HTML
1.5.4  การเรนเดอร์ฝั่งเซิร์ฟเวอร์ หมายถึง กระบวนการประมวลผลและสร้างเนื้อหาหน้าเว็บเพจสำเร็จรูปที่เครื่องแม่ข่ายก่อนส่งผลลัพธ์เป็นเอกสาร HTML ไปแสดงผลบนเว็บเบราว์เซอร์ของผู้ใช้
1.5.5  ปรากฏการณ์หน้าจอกระพริบ หมายถึง สภาวะที่หน้าเว็บแสดงผลในรูปแบบเริ่มต้นชั่วขณะก่อนที่สไตล์ชีตหรือธีมที่กำหนดจะถูกโหลดและประมวลผลเสร็จสิ้น
1.5.6  รหัสคิวอาร์ หมายถึง สัญลักษณ์รหัสแท่งสองมิติที่ใช้สำหรับเก็บข้อมูลรหัสสินทรัพย์และเชื่อมโยงไปยังหน้ารายละเอียดของครุภัณฑ์บนระบบ
1.5.7  นโยบายความปลอดภัยของเนื้อหา หมายถึง มาตรการความปลอดภัยบนส่วนหัวของโพรโทคอล HTTP เพื่อควบคุมและจำกัดแหล่งที่มาของสคริปต์ สไตล์ และการฝังเนื้อหาจากภายนอก
