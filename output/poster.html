บทคัดย่อ

โครงงานนี้จัดทำขึ้นเพื่อพัฒนาระบบบริหารจัดการสินทรัพย์ (Asset Management) ในรูปแบบเว็บแอปพลิเคชัน สำหรับคณะแพทยศาสตร์ โรงพยาบาลศรีนครินทร์ มหาวิทยาลัยขอนแก่น เพื่อแก้ไขปัญหาคอขวดในการสืบค้นข้อมูลครุภัณฑ์ที่เดิมจำกัดสิทธิ์เฉพาะแผนกพัสดุส่วนกลาง โดยผู้จัดทำรับผิดชอบพัฒนาในส่วนของส่วนต่อประสานผู้ใช้ (Frontend) ด้วย EJS, Bootstrap 5 และ Node.js/Express รองรับการแสดงผลตารางครุภัณฑ์ขนาดใหญ่พร้อม Sticky Header การโอนย้ายสินทรัพย์ระหว่างแผนกแบบกลุ่ม การสร้างและจัดพิมพ์ป้ายสติกเกอร์ QR Code ขนาด 70×24 มม. และรองรับระบบ Light/Dark Mode (Anti-FOUC)

วัตถุประสงค์
  • เพื่อพัฒนาระบบบริหารจัดการสินทรัพย์ในรูปแบบเว็บแอปพลิเคชัน สำหรับคณะแพทยศาสตร์ โรงพยาบาลศรีนครินทร์ มหาวิทยาลัยขอนแก่น
  • เพื่อออกแบบและพัฒนาส่วนต่อประสานผู้ใช้ (Frontend) รองรับตารางข้อมูลขนาดใหญ่ (Sticky Header), การโอนย้ายสินทรัพย์แบบกลุ่ม และการพิมพ์ป้าย QR Code
  • เพื่อพัฒนาระบบส่วนติดต่อผู้ใช้ที่รองรับ Responsive Design, รองรับโหมด Light/Dark Mode โดยไม่มีหน้าจอกระพริบ (Anti-FOUC) และระบบสองภาษา (i18n)
ประโยชน์ที่ได้รับ
  • ลดเวลาการสืบค้นและรอคอยข้อมูลสินทรัพย์ลงได้มากกว่า 75% บุคลากรแต่ละแผนกสามารถตรวจสอบสถานะครุภัณฑ์ในความดูแลได้โดยตรงแบบเรียลไทม์
  • ลดภาระงานและความซ้ำซ้อนของเจ้าหน้าที่แผนกพัสดุ ในการรับเรื่อง ตอบคำถาม และค้นหาประวัติครุภัณฑ์ย้อนหลัง
  • เพิ่มความโปร่งใสและแม่นยำในการโอนย้ายครุภัณฑ์ ตรวจสอบย้อนหลังได้ผ่าน Activity Logs และป้าย QR Code มาตรฐาน
ผลการดำเนินงาน (การทำงานจริงของเว็บแอปพลิเคชัน)
จากการพัฒนาส่วนต่อประสานผู้ใช้ (Frontend) ตัวเว็บแอปพลิเคชันทำงานได้สมบูรณ์และมีความพร้อมสำหรับนำไปติดตั้งใช้งานจริง (Production-Ready) โดยสรุปผลการทำงานของแต่ละฟังก์ชันได้ดังนี้:
1. แดชบอร์ดและตารางสินทรัพย์ (Large Table & Sticky Header)
ตารางข้อมูล 25 คอลัมน์ ทำงานร่วมกับ Scroll Wrapper เลื่อนดูได้ทั้งแนวตั้งและแนวนอนโดยหัวตารางตรึงอยู่กับที่ และ Limit Select รีเซ็ตกลับหน้า 1 อัตโนมัติ ป้องกันข้อมูลคลาดเคลื่อน
2. ระบบนำเข้าและเทียบผลต่าง Excel (Update with Diff)
หน้าจอ Diff Preview ตรวจจับและแยกกลุ่มข้อมูล (Changed, To Create, Unchanged) ได้อย่างแม่นยำ เลือกเปรียบเทียบค่าใหม่หรือค่าเดิมได้เป็นรายคอลัมน์ ป้องกันการเขียนทับผิดพลาด
3. ระบบโอนย้ายสินทรัพย์แบบกลุ่ม (Bulk Transfer & Combobox)
หน้าต่าง Modal แสดงป้ายแผนกต้นทางอัตโนมัติ และค้นหาแผนกปลายทางแบบ Search-as-you-type จากรายชื่อ 214 แผนกได้อย่างรวดเร็วผ่านแป้นพิมพ์
4. ระบบ QR Code และจัดพิมพ์ป้ายสติกเกอร์ (Print Label)
สร้าง QR Code ไดนามิก และสร้างหน้าสำหรับจัดพิมพ์สติกเกอร์ขนาด 70×24 มม. ตรงตามสเปกกระดาษจริง
5. ความสมบูรณ์ด้านการแสดงผลและความปลอดภัย (UI & Security)
สลับโหมด Light/Dark Mode ไร้ปัญหาหน้าจอกระพริบ (Anti-FOUC) และเปิดดู PDF ผ่าน iframe ภายใต้นโยบาย CSP ได้อย่างปลอดภัย ผ่านการทดสอบระบบครบถ้วน 80/80 กรณีทดสอบ (100%)
สรุปผลและข้อเสนอแนะ

สรุปผล: ระบบช่วยเพิ่มความคล่องตัวในการบริหารจัดการครุภัณฑ์ บุคลากรแต่ละแผนกเข้าถึงข้อมูลได้เองแบบเรียลไทม์ ตาราง Scroll Wrapper + Sticky Header ช่วยให้อ่านข้อมูล 25 คอลัมน์ได้สะดวก และพิมพ์ป้าย QR Code ได้ตามขนาดจริง
ข้อเสนอแนะ: ควรต่อยอดระบบสแกน QR Code ผ่านกล้องสมาร์ตโฟนบนหน้าเว็บเบราว์เซอร์โดยตรง และพัฒนาระบบแจ้งเตือนสัญญาประกันใกล้หมดอายุผ่าน Email / Line Notify
